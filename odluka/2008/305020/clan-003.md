# Član 3
Prilikom uručenja rješenja o prijemu u crnogorsko državljanstavo, lice daje svečanu izjavu. Svečana izjava daje se potpisivanjem obrasca iz člana 2 ove odluke.
Svečana izjava daje se pred službenim licem Ministarstva unutrašnjih poslova i javne uprave, u mjestu gdje je nastanjeno lice koje daje svečanu izjavu.
