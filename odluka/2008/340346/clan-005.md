# Član 5
U stavu 1 člana 3 poslije riječi: »radijskog« dodaju se riječi «i televizijskog«. Stav 2 mijenja se i glasi:
»Osnovnu djelatnost »RTUL« ostvaruje proizvodnjom i emitovanjem jednog programa Javnog radio - difuznog servisa »Radio Ulcinj« (u daljem tekstu: »Radio Ulcinj«) posredstvom jedne samostalne FM mreže i jednog programa Javnog radio -difuznog servisa »Televizija Ulcinj« (u daljem tekstu »Televizija Ulcinj«) posredstvom jedne samostalne UHF mreže«.
U stavu 3 poslije riječi »radijske« dodaju se riječi »i televizijske«.
