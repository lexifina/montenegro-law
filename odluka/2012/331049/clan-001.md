# Član 1
Ovom odlukom utvrđuju se visina, način i postupak kontrole namjenske potrošnje sredstava koja se opredjeljuju klubovima poslanika Skupštine Crne Gore za angažovanje sekretara, odnosno stručnog konsultanta kluba.
Klub poslanika može angažovati jednog sekretara i jednog ili više stručnih konsultanata.
