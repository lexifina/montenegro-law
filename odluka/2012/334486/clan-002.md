# Члан 2
Одбор из члана 1 ове одлуке чине осам посланика 24. сазива Скупштине, и то: четири посланика из странака парламентарне већине и четири из реда опозиције. Распоред чланова по странкама је сљедећи: два из Демократске партије социјалиста, један из Социјалдемократске партије, један из Бошњачке странке, један из Социјалистичке народне партије, један из Нове српске демократије, један из Покрета за промјене и један из редова албанских странака.
Предсједник Одбора је из Нове српске демократије.
Предсједника и чланове Одбора предлажу посланички клубови.
