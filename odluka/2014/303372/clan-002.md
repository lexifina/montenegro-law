# Član 2
Agenti pružalaca platnih usluga upisuju se u odgovarajuće registre pružalaca platnih usluga, i to:
1) agent banke i druge kreditne institucije sa sjedištem u Crnoj Gori upisuje se u
registar u koji se upisuju banke i druge kreditne institucije;
2) agent platne institucije sa sjedištem u Crnoj Gori upisuje se u registar platnih
institucija;
3) agent institucije za elektronski novac sa sjedištem u Crnoj Gori upisuje se u
registar institucija za elektronski novac;
4) agent ogranka kreditne institucije iz treće države sa sjedištem u Crnoj Gori upisuje
se u registar u koji se upisuju banke i druge kreditne institucije;
5) agent Centralne banke Crne Gore (u daljem tekstu: Centralna banka), odnosno
agent Države Crne Gore i jedinice lokalne samouprave kada ne djeluju u svojstvu
vlasti upisuju se u poseban registar koji vodi Centralna banka.
