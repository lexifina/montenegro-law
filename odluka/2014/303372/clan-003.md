# Član 3
Poslove agenta može obavljati samo pravno lice ili preduzetnik koji sa pružaocem platnih usluga u pisanoj formi zaključi ugovor o povjeravanju pružanja platnih usluga i koji se kao agent upiše u odgovarajući registar, u skladu sa odredbama ove odluke.
U slučaju kada je agent pružaoca platnih usluga drugi pružalac platnih usluga, taj pružalac platnih usluga ne može kroz RTGS sistem izvršavati platne transakcije koje obavlja kao agent.
