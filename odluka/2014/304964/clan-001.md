# Član 1
## o prodaji nepokretnosti neposrednom pogodbom Mudreša Vasku
Odobrava se prodaja nepokretnosti radi dokompletiranja urbanističke parcele UP 437 koja se nalazi u zahvatu Izmjena i dopuna DUP- a "Bogdanov kraj", neposrednom pogodbom Mudreša Vasku iz Cetinja, kako slijedi:
- kat.parcele br. 4694/3 iz lista nepokretnosti broj 403 KO Cetinje I, po kulturi građevinska parcela u površini od 35 m2, svojina Države Crne Gore, subjekat raspolaganja Prijestonice Cetinje.
