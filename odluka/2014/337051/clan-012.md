# Član 12
Procjena usklađenosti rada platnog sistema sa Principima za funkcionisanje platnih sistema može biti:
1) djelimična, kada se vrši procjena usklađenosti funkcionisanja platnog sistema
sa jednim ili više Principa za funkcionisanje platnih sistema, i
2) potpuna, kada se vrši procjena usklađenosti funkcionisanja platnog sistema sa
svim Principima za funkcionisanje platnih sistema.
