# Član 1
## o prodaji nepokretnosti neposrednom pogodbom Jovanović Drašku
Odobrava se prodaja nepokretnosti radi dokompletiranja urbanističke parcele UP 366 koja se nalazi u zahvatu DUP- a "Donji kraj" (Zona E), neposrednom pogodbom Jovanović Drašku iz Cetinja, kako slijedi:
-kat.parcele br.4698/4 iz lista nepokretnosti broj 2412 KO Cetinje I, po kulturi građevinska parcela u površini od 73 m2, svojina Države Crne Gore, subjekat raspolaganja Prijestonice Cetinje.
