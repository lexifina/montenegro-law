# Član 1
## o prodaji nepokretnosti neposrednom pogodbom Sulejman Hočku
Odobrava se prodaja nepokretnosti radi dokompletiranja urbanističke parcele UP 54 koja se nalazi u zahvatu DUP-UP- a "Istorijsko jezgro" blok 27a, neposrednom pogodbom, Sulejman Hočku iz Cetinja, kako slijedi:
-katastarske parcele br.3725/5 iz lista nepokretnosti broj 2411 KO Cetinje I, po kulturi građevinska parcela u površini od 8 m2, svojina Države Crne Gore, subjekat raspolaganja Prijestonice Cetinje i - katastarske parcele br.3726/3 iz lista nepokretnosti broj 404 KO Cetinje I, po kulturi građevinska parcela u površini od 1 m2, svojina Države Crne Gore, subjekat raspolaganja Prijestonice Cetinje.
