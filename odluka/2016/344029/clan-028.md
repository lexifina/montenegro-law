# Član 28
## Program rada
Starješine organa i službi lokalne uprave donose godišnji program rada uz saglasnost Predsjednika Opštine, a po pribavljenom mišljenju Glavnog administratora.
Program rada sadrži naročito: pregled poslova koji se planiraju, osnovnu sadržinu poslova, način izvšrenja i nosioce poslova, rokove za izvršenje (kvartalno, mjesečno) kao i druga pitanja vezana za vršenje programiranih poslova.
