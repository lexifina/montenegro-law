# Član 19
U članu 64 poslije prvog stava dodaje se novi stav 2 koji glasi:
" Pod unutrašnjom ( kućnom ) kanalizacijom podrazumjevaju se instalacije i objekti ( uređaji ) za odvođenje otpadnih voda iz zgrada i drugih objekata zaključno sa prvim revizionim oknom ( šahtom ). Prvo reviziono okno je dio kućne instalacije najbliži uličnoj kanalizacionoj mreži. " U članu 64 stav 2 poslije riječi " sabirnog okna " dodaju se riječi " ili revizionog okna ".
Dosadašnji stavovi ( 2 ) i (3 ) postaju (3 ) i ( 4 ).
