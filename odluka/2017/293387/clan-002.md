# Član 2
Površina zahvata Detaljnog urbanističkog plana "Desna obala Lima" u Beranama iznosi 34 ha, dok se izmjene odnose na prostor orijentacione površine od oko 12,5ha i to u dijelu UP4, UP 62, UP 64, UP 65, UP 67, UP 3, UP 1, UP 5, UP 6, UP 6a i UP 7 dok se ostale površine zadržavaju kao u osnovnom Planu.
