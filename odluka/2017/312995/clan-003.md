# Član 3
Planom ovaj prostor je planiran za:
• Industrijske sadržaje;
• Centralne djelatnosti;
• Površine školstva i socijalne zaštite;
• Površine mješovite namjene • Površine stambene namjene ( individualna i kolektivna) • zaštitno zelenilo;
• rekultivaciju prostora;
• saobraćajne površine.
• ostale namjene.
