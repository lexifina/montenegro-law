# Члан 2
Спомен-биста из члана 1 ове одлуке састоји се од попрсја изливеног у бронзи са ликом Гавра Вуковића и мермерног постамента, укупне висине 2,06 метара.
На зарубљеној бетонској пирамиди у основи, димензија 830 x 830, висине х= 250 мм, постављен је постамент од клесаног мермерног блока ( пешчаник ) димензија 600 x 600мм x 1.180 мм. На постаменту постављен је бронзани одливак - попрсје са ликом Гавра Вуковића, висине х-63 цм. Фронтално, на постаменту изведен је текст ћириличним писмом: ВОЈВОДА ГАВРО ВУКОВИЋ 1852-1928.
