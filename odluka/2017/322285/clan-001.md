# Član 1
## o davanju saglasnosti na Program rada i Finansijski plan Turističke organizacije opštine Žabljak za 2017.godinu
Daje se saglasnost na Program rada i Finansijski plan Turističke organizacije opštine Žabljak za 2017.godinu, broj 151/01 od 08.12.2016.godine, koje je donijela Skupština Turističke organizacije Žabljak.
