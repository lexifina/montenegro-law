# Član 22
Odluka o raspodjeli sredstava sadrži:
- naziv nevladine organizacije kojoj su dodijeljena sredstva;
- naziv projekta;
- konačnu ocjenu projekta,
- vrijeme realizacije projekta;
- iznos sredstava dodijeljenih od strane Komisije po svakom projektu pojedinačno;
- obrazloženje;
- uputstvo o pravnom sredstvu.
Odluka o raspodjeli sredstava dostavlja se učesnicima Konkursa i objavljuje se na web sajtu i oglasnoj tabli Opštine.
Na web sajtu Opštine objavljuju se projekti koji se finansiraju u tekućoj godini.
