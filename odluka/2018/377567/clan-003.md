# Члан 3
Непокретност из члана 1 ове одлуке се купују по повлашћеној цијени која за три стана износи укупно 84.800,00 € (95 m² x 640,00 € + 50 m² x 480,00 €), коју цијену је Општина Херцег Нови дужна уплатити "Црногорском фонду за солидарну стамбену изградњу" ДОО Подгорица одмах по закључењу уговора о купопродаји.
