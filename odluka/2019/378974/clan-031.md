# Član 31
Organ lokalne uprave donosi do kraja tekuće za narednu godinu program rada koji sadrži: pregled poslova koji se planiraju i njihovu sadržinu, način izvršenja i nosioce poslova, rokove za izvršenje kao i druge organe odnosno javne službe i organizacije koji učestvuju u vršenju planiranih poslova.
Program rada donosi starješina organa.
