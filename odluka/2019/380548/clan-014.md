# Члан 14
Уколико спортска организација по добијању финансијских средстава по огласу, не наступи на званичном такмичењу у наступајућој такмичарској сезони, односно иступи из такмичења који прописује матични спортски савез, спортска организација губи право суфинансирања из Буџета Општине за текућу годину.
