# Član 1
## ugrožene kategorije stanovništva
Prijestonica Cetinje kupuje nepokretnosti-šest stambenih prostora (garsonjera) za potrebe socijalno ugrožene kategorije stanovništva, koje nepokretnosti se nalaze na kat. parceli broj 4453/5 iz l.n. broj 3446 KO Cetinje I, svojina 1/1 Udruženje penzionera Cetinje i to:
Broj zgrade 1, PD 39, prizemlje, površine 27m2,
Broj zgrade 1, PD 43, prvi sprat, površine 27m2,
Broj zgrade 1, PD 47, potkrovlje-mansarda, površine 31m2,
Broj zgrade 1, PD 71, prizemlje, površine 27m2,
Broj zgrade 1, PD 75, prvi sprat, površine 27m2,
Broj zgrade 1, PD 79, potkrovlje-mansarda, površine 26m2.
