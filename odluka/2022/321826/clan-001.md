# Član 1
## DUP-a "Naselje 1.maj", u Podgorici
Prodaje se građevinsko zemljište u zahvatu DUP-a "Naselje 1.maj" ("Sl.list Crne Gore - opštinski proprisi", br.09/20 ), označeno kao:
- urbanistička parcela broj 147, površine 1.208m2, koju čine kat.parcela broj 1604/2 i kat.parcela broj 1607/4 iz lista nepokretnosti broj 177 KO Podgorica I,
- urbanistička parcela broj 147/, površine 861m2, koju čine kat.parcela broj 1604/3, kat.parcela broj 1607/5 i kat.parcela broj 1608/2 iz lista nepokretnosti broj 177 KO Podgorica I,
- urbanistička parcela broj 148, površine 1.357m2, koju čine kat.parcela broj 1604/4 i kat.parcela broj 1608/3 iz lista nepokretnosti broj 177 KO Podgorica I,
- urbanistička parcela broj 148/, površine 1.119m2, koju čine kat.parcela broj 1604/5, kat.parcela broj 1607/6 i kat.parcela broj 1608/4 iz lista nepokretnosti broj 177 KO Podgorica I.
Na navedenim urbanističkim parcelama planirana je izgradnja stambenih objekata maksimalne spratnosti P+4+M.
