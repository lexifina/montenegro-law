# Član 30
Organ lokalne uprave donosi godišnji program rada.
Program rada sadrži: pregled poslova koji se planiraju; osnovnu sadržinu poslova; način izvršenja i nosioce poslova; rokove za izvršenje, kao i organe lokalne uprave, javne službe i druge organizacije koje učestvuju u vršenju predviđenih poslova.
Program rada donosi starješina organa uz saglasnost Predsjednika Opštine do 31.12. tekuće godine za narednu godinu.
