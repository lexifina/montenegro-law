# Члан 1
## o продаји грађевинског земљишта Небојши Шипчићу ради докомплетирања урбанистичке парцеле број 3 у обухвату Детаљног урбанистичког плана Центар
Општина Никшић, продаје непосредном погодбом, Небојши Шипчићу из Никшића, земљиште укупне површине 617 м2, означено катастарском парцелом, број 2053/3, неплодно земљиште површине 500 м2, уписано у листу непокретности, број 787 КО Никшић, као својина Државе Црне Горе са правом располагања општине Никшић, катастарском парцелом, број 4559/4, неплодно земљиште површине 115 м2 и катастарском парцелом, број 4559/6, неплодно земљиште површине 2 м2, уписано у листу непокретности, број 764 КО Никшић, као својина Државе Црне Горе са правом располагања општине Никшић, по цијени од 199,37 € по м2 земљишта.
Земљиште из става 1 овог члана продаје се за потребе докомплетирања урбанистичке парцеле број 3 (урбанистички блок 5Ц), у складу са Одлуком о Детаљном урбанистичком плану Центар ("Службени лист Црне Горе-Општински прописи", број 50/18), на којој је планирана изградња стамбеног објекта, максималне спратности П+7.
