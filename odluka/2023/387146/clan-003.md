# Члан 3
Продаја земљишта из члана 1 став 1 ове одлуке, врши се по утврђеној цијени од 199,37 € по м2 земљишта, што за површину од 617 м2 укупно износи 123.000,00 € (заокружена вриједност), у складу са Извјештајем о процјени тржишне вриједности непокретности од 26.07.2023.године, урађеним од стране Комисије за процјену непокретних ствари у имовини општине Никшић формиране рјешењем Предсједника Општине Никшић број 02- 031-1584 од 16.06.2023. године.
Износ цијене из става 1 овог члана Небојша Шипчић је дужан уплатити у року од 60 дана од дана ступања на снагу ове одлуке, у противном покренуће се поступак за престанак важења исте.
