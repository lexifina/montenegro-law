# Члан 1
## о продаји грађевинског земљишта Веселину Миљанићу ради докомплетирања урбанистичке парцеле број 3 (блок 51) у обухвату Детаљног урбанистичког плана "Растоци 1"
Општина Никшић, продаје непосредном погодбом, Веселину Миљанићу из Никшића, земљиште укупне површине 333 м2, означено катастарском парцелом број 4551/3, грађевинска парцела, површине 95 м2 уписана у листу непокретности број 764 КО Никшић, као својина Државе Црне Горе са правом располагања општине Никшић и катастарском парцелом број 389/24, грађевинска парцела, површине 238 м2 уписана у листу непокретности број 787 КО Никшић, као својина Државе Црне Горе са правом располагања општине Никшић, по цијени од 82,00 € по м2 земљишта.
Земљиште из става 1 овог члана продаје се за потребе докомплетирања урбанистичке парцеле број 3 (блок 51), у складу са Одлуком о Детаљном урбанистичком плану "Растоци 1" ("Службени лист Црне Горе-Општински прописи", број 24/10), на којој је планирана изградња стамбеног објекта до максималне спратности С+ВП+3+Пк.
