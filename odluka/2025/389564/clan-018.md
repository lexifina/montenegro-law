# Član 18
## Odluka o sufinansiranju programa rada
Nadležni organ, na predlog Komisije, donosi Odluku o sufinansiranju programa rada sportskih organizacija.
Odluka o sufinansiranju programa rada sportskih organizacija objavljuje se na web sajtu Opštine, oglasnoj table Opštine i putem lokalnog javnog emitera.
Učesnik konkursa ima pravo prigovora na Odluku o sufinansiranje programa rada sportskih organizacija u roku od 8 dana, koja se podnosi preko nadležnog organa, Glavnom administratoru Opštine Danilovgrad.
