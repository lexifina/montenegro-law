# Član 1
## o donošenju Programa obavljanja komunalnih djelatnosti "Zelenilo" d.o.o. Podgorica za 2026. godinu
Donosi se Program obavljanja komunalnih djelatnosti "Zelenilo" d.o.o. Podgorica za 2026. godinu, koji je Odlukom br. OD/11050/1 usvojio Odbor direktora Društva, na sjednici održanoj 4. decembra 2025. godine.
