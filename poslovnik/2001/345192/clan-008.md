# Član 8
Radi ostvarivanja funkcija i izvršavanja zadataka zbog kojih je osnovan, Savjet usvaja program rada.
Program rada utvrđuje se za period od jedne godine.
Program rada može se utvrditi i za kraći period od jedne godine ako Savjet ustanovi da je to neophodno radi ostvarivanja utvrđenih funkcija i izvršavanja zadataka.
