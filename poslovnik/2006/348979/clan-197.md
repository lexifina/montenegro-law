# Član 197
Glasanje o nepovjerenju, odnosno povjerenju Vladi vrši se javnim glasanjem.
Glasanje o nepovjerenju vrši se na način što se poslanici izjašnjavaju "za nepovjerenje" ili "protiv nepovjerenja".
Glasanje o povjerenju vrši se na način što se poslanici izjašnjavaju "za povjerenje" ili "protiv povjerenja".
Ako Vlada izgubi povjerenje, predsjednik Skupštine o tome odmah obavještava Predsjednika Republike.
