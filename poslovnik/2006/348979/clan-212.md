# Član 212
Radi obezbjeđivanja potpunijeg informisanja javnosti o radu Skupštine, Skupština ima svoj web site na kojem objavljuje podatke i informacije o radu Skupštine i njenih odbora.
Prezentacija Skupštine i njenih odbora na web site-u uređuje se posebnim aktom Kolegijuma predsjednika Skupštine.
