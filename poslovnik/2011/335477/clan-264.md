# Član 264
## 2.4. Upisnici privrednih sudova
Privredni sudovi vode upisnike za:
1) parnične predmete "P" (obrazac broj 26),
2) sporove male vrijednosti "Mal" (obrazac broj 27),
3) platne naloge "Pl" (obrazac broj 28),
4) predmete izvršenja "I" (obrazac broj 29),
5) složene vanparnične predmete "Rs" (obrazac broj 31),
6) predmete pravne pomoći "Pom" i "Pom-I" (obrazac broj 32),
7) razne građanske i vanparnične predmete "R" (obrazac broj 38),
8) za upise brodova "R" (Ub) i upise vazduhoplova "R" (Uv) (obrazac broj 39),
9) predmete stečaja "St" (obrazac broj 40),
10) predmete likvidacije "L" (obrazac broj 41).
