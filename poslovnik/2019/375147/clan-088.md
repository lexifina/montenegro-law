# Члан 88
## Одлучивање
Скупштина одлучује ако сједници присуствује више од половине укупног броја одборника, а одлуку доноси већином гласова присутних одборника, ако Статутом општине није дугачије одређено.
Скупштина одлучује о сваком питању које је стављено на дневни ред, по правилу послије завршене расправе.
