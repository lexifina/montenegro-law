# Члан 147
Представницима невладиних организација који су одређени да учествују у раду сједнице, доставља се позив за сједницу са материјалом за тачку дневнога реда по којој учествују, најкасније 5 дана прије одржавања сједнице.
Обавјештење о представницима невладиних организација који ће по појединим тачкама дневног реда присуствовати сједници Скупштине, објављује се на web сајту Скупштине.
