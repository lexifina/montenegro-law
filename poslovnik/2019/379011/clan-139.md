# Član 139
Predsjednik Skupštine, gradonačelnik, radno tijelo Skupštine i odbornik mogu uz obrazloženje predložiti nakasnije 3 dana prije održavanja sjednice da se pojedina pitanja unesu u program rada Skupštine.
O predlozima iz prethodnog stava nakon izjašnjenja gradonačelnika Skupština odlučuje bez pretresa.
