# Član 7
Iznos Osnovne uplate se izračunava pomoću sljedeće formule:
OU= (( St-1 * Pt-1 ) / Č ) *2
pri čemu je :
OU = osnovna uplata
St-1 = prosječne obaveze svih Članova učesnika iz prethodne godine,
Pt-1 = prosječni udio Članova učesnika neto dužnika u odnosu na sve Članove učesnike u prošloj godini
Č = broj Članova učesnika
2 = dva dana trajanja kliringa i saldiranja
