# Члан 18
За превод писаног текста тумачу припада награда која се рачуна по реду извршеног превода откуцаног на писаћој машини, с тим што се сваки започети ред рачуна као цијели ред.
Висина награде износи:
1. за превод са језика једног народа, односно народности Југославије на страни језик, за сваки откуцани ред 0,25% од просјечно мјесечно исплаћеног чистог личног дохотка по раднику у привреди Републике Црне Горе за претходно полугодиште (у даљем тексту: лични доходак), с тим да награда не може бити мања од 4,5% од личног дохотка;
2. за превод са страног језика на језик народа, односно народности Југославије, за сваки откуцани ред 0,20% од личног дохотка, с тим да награда не може бити мања од 3,5% од личног дохотка;
3. за превод са страног језика на други страни језик, за сваки откуцани ред 0,35% од личног дохотка, с тим да награда не може бити мања од 5% од личног дохотка;
4. за превод са језика једног народа, односно народности Југославије на језик другог народа, односно народности Југославије, за сваки откуцани ред 0,15% од личног дохотка, с тим што награда не може бити мања од 2,5% од личног дохотка.
За превод научних или стручних текстова тумачу награда из става 2. овог члана може се повећати највише до 50%.
