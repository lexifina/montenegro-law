# Члан 3
Из контигента могућих матичних бројева, надлежна подручна организациона јединица грађанину одређује матични број који одговара чињеницама садржаним у изводу из матичне књиге рођених.
Поред матичног броја одређеног на начин из става 1. овог члана на листингу могућих матичних бројева сигнира се редни број регистра под којим је матични број који је одређен евидентиран.
