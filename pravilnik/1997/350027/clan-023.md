# Члан 23
Према утврђеним индикацијама осигураницима се обезбјеђују наочаре, ca:
1. Корекционим стаклима за корекцију аметропије и пресбиогдаје,
2. Лентикуларким стаклима, код операције од катаракте,
3. Корекционим стаклима од пластике у случају диоптрије веће од 5 код дјеце до 14 година, a за остале осигуранике код диоптрије веће од 10,
4. тамне наочаре без диоптрије у сљедећим случајевима:
- код унакажења спољашњих дјелова ока,
- капка (entropiju, ektropiju, већег степена, anophtalmus, corneosymblepharon,) код ceratocowuctivitis philketeulosa (када je захваћена рожњача послије перманентног лијечења од најмање мјесец дана или кад они рецидивирају).
