# Član 3
Ako je korisnik fizičko lice, u bazu podataka se unose sljedeći podaci:
- ime i prezime,
- adresa,
- broj lične karte ili pasoša,
- jedinstveni matični broj (JMBG),
- datum i vrijeme izdavanja kartice,
- dodijeljeni korisnički broj,
- podaci o prodajnom mjestu.
Ako je korisnik pravno lice, u bazu podataka se unose sljedeći podaci:
- naziv pravnog lica,
- sjedište, odnosno adresa na koju se šalju dopisi ako se razlikuje,
- poreski identifikacioni broj (PIB),
- podaci o odgovornom licu,
- datum i vrijeme izdavanja kartice,
- dodijeljeni korisnički broj,
- podaci o prodajnom mjestu.
