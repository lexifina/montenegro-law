# Član 199
## Broj učenika
Javna ustanova dom učenika se može osnovati ako ima najmanje 30 učenika, odnosno dom učenika i studenata ako ima najmanje 50 učenika odnosno studenata, a dom studenata ako ima najmanje 80 studenata.
Privatna ustanova dom učenika se može osnovati ako ima najmanje 20 učenika, odnosno dom učenika i studenata ako ima najmanje 40 učenika odnosno studenata, a dom studenata ako ima najmanje 50 studenata.
