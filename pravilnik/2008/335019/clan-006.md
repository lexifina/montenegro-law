# Član 6

20%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - dvije zarade;
-
30%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - tri zarade;
-
40%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - četiri zarade;
-
50%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - pet zarada;
-
60%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - šest zarada;
-
70%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - sedam zarada;
-
80%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - osam zarada;
-
90%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - devet zarada i
-100%,
tjelesnog oštećenja, odnosno vojnog invaliditeta - deset zarada.
