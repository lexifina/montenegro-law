# Član 43
## Utvrđivanje opšteg uspjeha
Ispitni centar utvrđuje rezultate uspjeha kandidata iz svih dijelova ispita i dostavlja ih školi.
Kandidat je položio stručni ispit ako je iz svih dijelova ispita ocijenjen pozitivnom ocjenom.
Opšti uspjeh se računa kao aritmetička sredina ocjena iz pojedinih predmeta.
Kandidat je stručni ispit završio sa:
- odličnim uspjehom, ako je postigao prosječnu ocjenu najmanje 4,50;
- vrlo dobrim uspjehom, ako je postigao prosječnu ocjenu najmanje 3,50;
- dobrim uspjehom, ako je postigao prosječnu ocjenu najmanje 2,50;
- dovoljnim uspjehom, ako je postigao prosječnu ocjenu najmanje 2.
