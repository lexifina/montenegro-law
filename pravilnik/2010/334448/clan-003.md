# Члан 3
Овлашћено привредно друштво, односно друго правно лице за вршење послова припреме справа из члана 1 овог правилника за овјеравање, приликом поправке справа, не смије уклонити државни жиг постављен на справи, без присуства службеника Завода за метрологију (у даљем тексту: Завод).
Након поправке справа из става 1 овог члана, врши се њихово овјеравање.
Овјеравање справа из става 2 овог члана, врши се у радним условима на мјесту коришћења справа.
