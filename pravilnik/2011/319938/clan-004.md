# Član 4
Pojedini izrazi upotrijebljeni u ovom pravilniku imaju sljedeća značenja:
1) Hardversko - softverska struktura je sva neophodna elektronska i programska
oprema;
2) korisnička aplikacija je izvršni kompjuterski program koji se upotrebljava za određenu
vrstu posla;
3) Web aplikacija je izvršni Internet program koji se upotrebljava za određenu namjenu;
4) Web servis je dio aplikacije namijenjen standardizovanoj razmjeni podatka; 5) analogni oblik podataka predstavlja sve vrste klasičnih izvora podataka;
6) baza podataka je skup sistematizovanih podataka u elektronskom ili analognom obliku
o kulturnim dobrima.
