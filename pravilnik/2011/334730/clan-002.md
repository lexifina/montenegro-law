# Члан 2
Корисник из члана 1 овог правилника, којем је омогућен непосредан приступ под- ацима из Централног регистра за чије је коришћење законом овлашћен, дужан је да о- дреди одговорно лице овлашћено за приступ тим подацима.
Подацима из Централног регистра може приступити и друго лице запослено код к- орисника, уз сагласност одговорног лица из става 1 овог члана.
