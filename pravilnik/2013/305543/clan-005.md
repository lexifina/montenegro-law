# Član 5
Interni oglas unutar Službe Skupštine objavljuje se na oglasnoj tabli, intranetu i web stranici Skupštine Crne Gore www.skupstina.me, kao i na web stranici organa za upravljanje kadrovima.
Interni oglas između državnih organa objavljuje se na web stranici Skupštine Crne Gore www.skupstina.me, kao i na web stranici organa za upravljanje kadrovima.
Javni oglas i javni konkurs objavljuju se na web stranici Skupštine Crne Gore www.skupstina.me, na web stranici organa za upravljanje kadrovima i u dnevnim novinama koje se distribuiraju na cjelokupnoj teritoriji Crne Gore, posredstvom Zavoda za zapošljavanje.
