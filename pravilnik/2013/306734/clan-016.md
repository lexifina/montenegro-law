# Član 16
Oznaka standarda odbrane sastoji se iz tri dijela:
- prvi dio je oznaka kojom se obilježava standard i sastoji se od velikih štampanih slova latinice "SO" ;
- drugi dio oznake sastoji se od četri cifre (arapske),kojim se obilježava redni broj standarda, počev od broja 1000;
- treći dio se sastoji od dvije cifre (arapske) koje se odnose na godinu izdavanja tog standarda.
