# Član 19
Prilozi standarda odbrane, odnosno preuzeti strani standard odbrane označavaju se tako što se riječ "prilog" piše velikim štampanim slovima latinice, a njihove stranice se numerišu pripadajućim slovom i rednim brojem (npr.PRILOG C 1).
Na prvoj strani priloga iz stava 1 ovog člana, nalazi se oznaka standarda odbrane, odnosno preuzetog stranog standarda odbrane uz koju se prilog navodi (npr. PRILOG C uz SO 1030)
