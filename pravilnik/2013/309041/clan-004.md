# Član 4
Registar dozvola vodi se u elektronskoj formi.
U Registar dozvola upisuju se sljedeći podaci;
Osnovni podaci o dozvoli:
-
redni broj dozvole
-
datum upisa;
-
mjesto izdavanja;
-
datum izdavanja;
-
vrijeme započinjanja djelatnosti;
-
period važenja dozvole;
-
iznos naknade.
Podaci o lokaciji uzgajališta:
-
zona za marikulturu;
-
naziv uzgajališta;
-
prostorne koordinate lokacije uzgajališta;
-
površina uzgajališta (m2).
Podaci o vrstama koje se uzgajaju:
-
vrste i količina ribe, školjaka ili drugih morskih organizama koji se uzgajaju (t/god). Podaci o nosiocu dozvole:
-
naziv i sjedište odnosno ime, prezime i adresa nosioca dozvole;
-
PIB/JMB;
-
tel/fax/e-mail;
-
fotografija uzgajališta.
