# Član 3
## Program osposobljavanja
Program osposobljavanja sastoji se iz teorijskog i praktičnog dijela. Teorijski dio
osposobljavanja obuhvata:
1) poznavanje propisa koji se odnose na držanje i nošenje i pravilnu upotrebu oružja;
2) bezbjedno rukovanje oružjem;
3) osnove balistike i tehnika gađanja.
Praktični dio osposobljavanja obuhvata:
1) bezbjedno rukovanje oružjem;
2) praktično gađanje oružjem.
Program osposobljavanja sastavni je dio ovog pravilnika.
