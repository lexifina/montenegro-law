# Član 8
## Sadržaj Web Portala
Sadržaj Web portala, kao i podportala Predsjednika Vlade, potpredsjednika Vlade, Generalnog sekretarijata Vlade i Biroa za odnose s javnošću uređuje Biro za odnose s javnošću Vlade Crne Gore.
Sadržaj podportala drugih državnih organa uređuju administratori uz saglasnost odgovornog lica iz državnog organa.
