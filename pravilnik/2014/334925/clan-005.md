# Član 5
## Formiranje MMSI broja
MMSI broj za identifikaciju radio stanice se sastoji iz stalnog dijela i promjenljivog dijela.
Stalni dio - MID znak (MID - Maritime Identification Digits) se sastoji od tri cifre "262", koje u skladu sa međunarodnim propisima označavaju da je plovilo registrovano u Crnoj Gori.
Promjenljivi dio MMSI broja se sastoji od kombinacije cifara od 0 do 9.
Plovilu se dodjeljuje MMSI broj u formatu M1I2D3X4 X5 X6 X7 X8 X9, gdje je X bilo koja cifra od 0 do 9.
Grupi plovila se dodjeljuje MMSI broj u formatu 01M2I3D4X5 X6 X7 X8 X9, gdje je X bilo koja cifra od 0 do 9.
Obalnoj radio stanici se dodjeljuje MMSI broj u formatu 0102M3I4D5X6 X7 X8 X9, gdje je X bilo koja cifra od 0 do 9.
