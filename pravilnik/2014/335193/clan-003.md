# Član 3
U evidenciju stanišnih tipova u šumama pored podataka iz člana 2 ovog pravilnika,
unose se i sljedeće podaci :
- velika mrtva stabla (distribucija, status truljenja);
- drveće velikog prečnika (distribucija);
- "porijeklo" šume (% primarnih visokih šuma, % sekundarnih visokih šuma, % izdaničkih
šuma, % plantaža vještačkih šuma).
Evidencija iz stava 1 ovog člana vodi se na Obrascu 2 koji je sastavni dio ovog pravilnika.
