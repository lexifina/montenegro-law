# Član 12
## Upotreba i struktura ID broja
Kako bi se osiguralo ispravno usmjeravanje poziva prema prenesenim brojevima, u razmjeni signalizacije uz nacionalni broj koji je predmet uspostave poziva, polazni operator poslaće operatoru kod koga je broj prenesen pridruženi ID broj operatora kome se poziv usmjerava, ispred koga će se nalaziti prefiks #14 rezervisan preporukom ITU-T Q.850.
Broj koji označava telekomunikacionu mrežu (NetID) određuje Agencija, dok broj koji označava komutacioni čvor (NodeID) određuje operator.
Struktura ID broja je data kako slijedi:
ID Broj
NetID
NodeID
00-99 (dvije cifre)
0-9 (jedna cifra)
