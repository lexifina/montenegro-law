# Član 3
## Značenje izraza
Izrazi upotrijebljeni u ovom pravilniku imaju sljedeća značenja:
1) Web portal je javni informacioni i komunikacioni servis Vlade Crne Gore (u daljem tekstu: Vlada) ;
2) podportal - je dio Web portala koji predstavlja posebnu logičku i sadržajnu cjelinu;
3) glavni administrator Web portala je lice koje upravlja Web portalom i priprema uputstvo za korišćenje i ažuriranje Web portala;
4) administrator podportala je lice koje uređuje sadržaj podportala i koje je zaduženo za administraciju podportala.
