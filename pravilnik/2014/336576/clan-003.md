# Član 3
## Obrazovanje komisija
Komisije obrazuje organ državne uprave nadležan za poslove socijalnog staranja ( u daljem tekstu: Ministarstvo).
Komisije se obrazuju kao Prvostepena socijalno-ljekarska komisija (u daljem tekstu: Prvostepena komisija) i Drugostepena socijalno-ljekarska komisija ( u daljem tekstu: Drugostepena komisija).
