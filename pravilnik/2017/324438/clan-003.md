# Član 3
## Plan rješavanja stambenih potreba državnih tužilaca
Rješavanje stambenih potreba državnih tužilaca ostvaruje se prema planu za rješavanje stambenih potreba koji donosi Tužilački savjet najkasnije 60 dana od dana donošenja Budžeta Crne Gore za tekuću godinu.
Plan sadrži:
1. Broj stanova koji će se izgraditi, kupiti, odnosno obezbjediti radi:
- davanja po osnovu zakupa,
- kupovine pod povoljnijim uslovima;
- kupovine stanova izgrađenih u javno-privatnom partnerstvu i ugovorom o udruživanju sredstava;
2. Iznose sredstava za dodjelu kredita za:
- izgradnju ili kupovinu stana,
- poboljšanje uslova stanovanja,
- zamjenu stana;
3. Podatke o građevinskom zemljištu koje će se obezbjediti za rješavanje stambenih potreba državnih tužilaca (lokacija, površina, i sl.);
4. Ukupan iznos sredstava koji će se obezbjediti po namjenama i usmjeriti (koristiti) za rješavanje stambenih potreba državnih tužilaca.
