# Član 3
U prvi red unose se:
- oznaka vrste dokumenta - dva znaka (1-2);
- oznaka države izdavanja "MNE" - tri znaka (3-5);
- broj dozvole - devet znakova (6-14);
- kontrolni broj dozvole - jedan znak (15);
- jedinstveni matični broj stranca - 13 znakova (16-28);
- filter znakovi (< <) - dva znaka (29-30).
