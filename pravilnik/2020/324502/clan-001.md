# Član 1
U Pravilniku o obrascima isprava o oružju ("Službeni list CG", broj 35/15) u članu 4 stav 2 poslije riječi: " 'ORUŽNI LIST ZA DRŽANJE ORUŽJA';" dodaju se riječi: "ugraviran element 'MNE';", a riječi: "broj i datum prestanka važenja" zamjenjuju se riječima: "broj oružnog lista, datum do kojeg važi".
Poslije stava 2 dodaje se novi stav koji glasi:
"Na prednjoj strani oružnog lista za držanje oružja, u pozadini obrasca, nalazi se naziv 'Crna Gora'."
U stavu 3 poslije riječi "rijekama," dodaju se riječi: "oznaku Crne Gore - MNE štampanu optički varijabilnim mastilom sa efektom pomjeranja u bojama roze do zelene, promjenljivu lasersku sliku (CLI), ugraviran zaštitni element 'CG',".
Dosadašnji stav 3 postaje stav 4.
