# Član 2
## Način vođenja i održavanja Informacionog sistema
Informacioni sistem vodi se u digitalnom obliku na način kojim se obezbeđuje:
- organizacija načina rada;
- popis subjekata izvještavanja;
- način i rokovi dostavljanja podataka;
- način upravljanja podacima i informacijama.
Održavanje Informacionog sistema obuhvata:
- održavanje baza podataka;
- obezbjeđivanje kontinuiranog korišćenja sistema od strane eksternih korisnika;
- evidentiranje i otklanjanje nedostataka sistema;
- oporavak baze podataka u slučaju potrebe;
- održavanje sistema zaštite podataka;
- arhiviranje podataka;
- održavanje računarske, programske i komunikacione opreme.
