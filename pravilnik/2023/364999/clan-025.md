# Član 25
Rokovi trajanja djelova uniforme policijskih službenika uže organizacione jedinice Grupa za protivdiverzionu zaštitu, izraženi u godinama, su:
1) kratka jakna sa podjaknom - 4;
2) duga jakna - 4;
3) ljetnje pantalone - 2;
4) zimske pantalone - 2;
5) termo (aktivni) veš - 2;
6) košulja kratkih rukava - 2;
7) košulja dugih rukava - 2;
8) polo majica kratkih rukava - 2;
9) polo majica dugih rukava - 2;
10) džemper - rolka - 2;
11) majica kratkih rukava (T-shirt majica) - 2;
12) ljetnja kapa - 2;
13) zimska kapa - 2;
14) zimske rukavice - 2;
15) ljetnje čarape - 2;
16) zimske čarape - 2;
17) ljetnje taktičke patike - cipele - 2;
18) zimske taktičke patike - cipele - 2;
19) kišno odijelo - 4;
20) ranac - 5; i
21) transportna torba - 5.
