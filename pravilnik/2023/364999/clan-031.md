# Član 31

1) sako - 1;
2) taktička jakna - 2;
3) mantil - 4;
4) košulja kratkih rukava - 1;
5) košulja dugih rukava - 1;
6) pantalone - 1;
7) kaiš - 5;
8) kravata - 1;
9) čarape - 1;
10) taktička torbica - 2;
11) taktički prsluk - 4;
12) plitke cipele - 1;
13) taktičke pantalone - 2;
14) taktička bluza - 2;
15) taktička majica - 2,
16) taktičke patike - cipele - 2,
17) kapa - 2;
18) polo majica - 2; i
19) taktičke rukavice - 4.
