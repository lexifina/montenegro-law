# Član 32
Rokovi trajanja djelova uniforme policijskih službenika koji obavljaju poslove obezbjeđenja ličnosti i objekata za žene, izraženi u godinama, su:
1) sako - 1;
2) taktička jakna - 2;
3) mantil - 4;
4) košulja kratkih rukava - 1;
5) košulja dugih rukava - 1;
6) suknja - 1;
7) pantalone - 1;
8) kaiš - 5;
9) kravata ili marama - 1;
10) čarape - 1;
11) taktička torbica - 2;
12) taktički prsluk - 4;
13) plitke cipele - 1;
14) taktičke pantalone - 2;
15) taktička bluza - 2;
16) taktička majica - 2;
17) taktičke patike - cipele - 2;
18) kapa - 2;
19) polo majica - 2; i
20) taktičke rukavice - 4.
