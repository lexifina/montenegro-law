# Član 36
Rokovi trajanja djelova uniforme policijskih službenika Ministarstva koji vrše bezbjednosnu zaštitu Centra za prihvat, izraženi u godinama, su:
1) taktička kratka jakna sa podjaknom - 4;
2) taktička duga jakna - 4;
3) taktičke zimske pantalone - 2;
4) taktičke ljetnje pantalone - 2;
5) polo majica kratkih rukava - 2;
6) polo majica dugih rukava - 2;
7) košulja kratkih rukava - 2;
8) košulja dugih rukava - 2;
9) taktički džemper - 2;
10) termo (aktivni) veš - 2;
11) ljetnje čarape - 2;
12) zimske čarape - 2;
13) majica kratkih rukava (T-shirt majica) - 2;
14) ljetnja kapa - 2;
15) zimska kapa - 2;
16) zimske rukavice - 2;
17) rukavice za pretres lica i stvari (anti cut) - 1;
18) ljetnje taktičke cipele - 2;
19) zimske taktičke cipele - 2;
20) kišno odijelo - 4;
21) taktičke čizme - 2; i
22) ranac - 8.
