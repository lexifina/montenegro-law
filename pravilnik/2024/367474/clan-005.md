# Član 5
## Dostavljanje podataka obveznika u formi analitičke kartice
Podatke iz člana 90 stav 1 tačka 3 Zakona koji se odnose na promet sredstava obveznici dostavljaju u formi analitičke kartice, prema sljedećem redosljedu:
- za plaćanja unutar Crne Gore: datum vršenja transakcije; naziv i matični broj obveznika (kreditne institucije izvjestioca); broj računa klijenta (pravnog ili fizičkog lica za koje se traže podaci), uključujući prve tri cifre koje se odnose na kreditnu instituciju; broj naloga transakcije, uplata, isplata, valuta, svrha plaćanja, vrsta transakcije (gotovina, prenos), način vršenja transakcije (šalter, post terminal, e-banking, ATM, interni prenos); naziv pravnog, odnosno ime i prezime fizičkog lica koje vrši uplatu odnosno prima sredstva (lice kontra); matični broj pravnog, odnosno jedinstveni matični broj fizičkog lica koje vrši uplatu odnosno prima sredstva; država izdavanja lične isprave lica koje vrši uplatu odnosno prima sredstva (popunjava se za fizička lica, za pravna lica je prazno); broj računa lica koje vrši uplatu odnosno prima sredstva, uključujući prve tri cifre koje se odnose na kreditnu instituciju; naziv i matični broj kreditne institucije kod koje je otvoren račun lica koje vrši uplatu odnosno prima sredstva; stanje na računu klijenta; vrijeme izvršenja transakcije;
- za inostrana plaćanja: datum vršenja transakcije; naziv i matični broj obveznika (kreditne institucije izvjestioca); broj računa klijenta (pravnog ili fizičkog lica za koje se traže podaci), uključujući prve tri cifre koje se odnose na kreditnu instituciju; broj naloga transakcije, uplata, isplata, valuta, svrha plaćanja, vrsta transakcije (gotovina, prenos, konvertovanje), način vršenja transakcije (šalter, post terminal, e-banking, ATM, interni prenos); naziv pravnog, odnosno ime i prezime fizičkog lica koje vrši uplatu odnosno prima sredstva (lice kontra); matični broj pravnog, odnosno jedinstveni matični broj fizičkog lica koje vrši uplatu odnosno prima sredstva; država izdavanja lične isprave lica koje vrši uplatu odnosno prima sredstva (popunjava se za fizička lica, za pravna lica je prazno); država iz koje je pravno, odnosno fizičko lice koje vrši uplatu odnosno prima sredstva; broj računa lica koje vrši uplatu odnosno prima sredstva (kompletan broj računa uključujući IBAN); naziv kreditne institucije kod koje je otvoren račun lica koje vrši uplatu odnosno prima sredstva, država kreditne institucije kod koje je otvoren račun lica koje vrši uplatu odnosno prima sredstva, SWIFT kod kreditne institucije kod koje je otvoren račun lica koje vrši uplatu odnosno prima sredstva; naziv kreditne institucije koja je korespondent, država kreditne institucije koja je korespondent; stanje na računu klijenta; vrijeme izvršenja transakcije.
U analitičku karticu iz stava 1 ovog člana unose se svi podaci, osim u slučaju kad u vršenju transakcije učestvuje samo jedno lice (npr. u slučaju deponovanja ili podizanja sredstava sa vlastitog računa).
Izuzetno od stava 1 ovog člana, obveznik koji je pružalac platnih usluga ili Pošta Crne Gore podatke iz člana 90 stav 1 tačka 3 Zakona koji se odnose na promet sredstava dostavljaju u formi analitičke kartice, prema sljedećem redosljedu:
1) broj naloga transakcije; iznos, valuta, datum slanja novca, vrijeme slanja novca, datum prijema novca, vrijeme prijema novca; ime platioca, prezime platioca, adresa platioca, grad platioca, poštanski broj platioca, država platioca, broj telefona platioca, datum rođenja platioca, broj lične isprave platioca, vrsta lične isprave platioca, država izdavanja lične isprave platioca, zanimanje platioca; status transakcije (izvršena, otkazana); ime primaoca plaćanja, prezime primaoca plaćanja, adresa primaoca plaćanja, grad primaoca plaćanja, poštanski broj primaoca plaćanja, država primaoca plaćanja, broj telefona primaoca plaćanja, datum rođenja primaoca plaćanja, broj lične isprave primaoca plaćanja, vrsta lične isprave primaoca plaćanja, država izdavanja lične isprave primaoca plaćanja; naziv pružaoca platnih usluga platioca, država pružaoca platnih usluga platioca; naziv pružaoca platnih usluga primaoca plaćanja, država pružaoca platnih usluga primaoca plaćanja; država rođenja platioca; država rođenja primaoca plaćanja; veza između platioca i primaoca plaćanja; svrha transakcije; ili
2) broj naloga transakcije; matični broj obveznika (pružaoca platnih usluga izvjestioca); jedinstveni matični broj ovlašćenog lica za sprečavanje pranja novca i finansiranja terorizma; ime platioca, prezime platioca, rezidentnost platioca, jedinstveni matični broj platioca, datum rođenja platioca, državljanstvo platioca, država platioca, adresa platioca, grad platioca, vrsta lične isprave platioca, broj lične isprave platioca; ime primaoca plaćanja, prezime primaoca plaćanja, rezidentnost primaoca plaćanja, jedinstveni matični broj primaoca plaćanja, datum rođenja primaoca plaćanja, državljanstvo primaoca plaćanja, država primaoca plaćanja, adresa primaoca plaćanja, grad primaoca plaćanja, vrsta lične isprave primaoca plaćanja, broj lične isprave primaoca plaćanja; svrha transakcije, datum i vrijeme transakcije, iznos, filijala, status transakcije; napomena.
