# Član 3
## Mjere za spriječavanje diskriminatornog postupanja
Program podrazumijeva uspostavljanje i sprovođenje unutrašnjih procedura CEDIS-a koje će spriječiti postojanje povlašćene pozicije određenih korisnika distributivnog sistema u odnosu na ostale korisnike, naročito vezane za pristup distributivnom sistemu i korišćenje usluga CEDIS-a.
