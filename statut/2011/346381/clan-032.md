# Član 32
## 1.4.2. Klubovi odbornika
U Skupštini se obrazuju klubovi odbornika.
Svaka politička partija ( partijska izborna lista ), koalicija političkih partija ( koaliciona izborna lista), odnosno grupa građana ( izborna lista grupe građana ), koja je na izborima osvojila najmanje dva mandata, ima pravo da obrazuje klub odbornika.
Sa koalicione liste dvije ili više političkih partija, odnosno grupe građana, mogu se obrazovati jedan ili više klubova shodno koalicionom ugovoru, odnosno sporazumu.
