# Član 106
Starješina organa, odnosno službe može imati pomoćnika.
Pomoćnik starješine organa, odnosno službe postavlja se na osnovu javnog konkursa, na vrijeme od pet godina.
Odluku o postavljenje pomoćnika starješine organa, odnosno službe donosi starješina organa, odnosno službe, uz saglasnost predsjednika opštine.
Pomoćniku starješine organa, odnosno službe prestaje mandat i razrješava se zbog razloga iz člana 79 i 80 zakona.
