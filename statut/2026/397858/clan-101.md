# Član 101
Predsjednik Opštine bira se javnim glasanjem, ako Skupština drugačije ne odluči.
Kada se izbor za predsjednika Opštine vrši javno glasanje se vrši prozivkom odbornika I jasnim izgovaranjem riječi "za", "protiv" i "uzdržan".
Ako je za predsjednika Opštine predloženo više kadidata izbor se vrši tajnim glasanjem.
Tajno glasanje se vrši shodno odredbrama Statuta kojima se udređuje izbor predsjednika Skupštine.
