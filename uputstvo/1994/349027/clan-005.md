# Члан 5
На лична примања по основу накнаде за вријеме боловања преко 30 дана обрачунавају се обавезе по основу јавних прихода, и то:
(1) порез на лична примања по стопи од 32%;
(2) допринос за пензијско и инвалидско осигурање по стопи од 24% и допринос за осигурање од незапослености по стопи од 0,5% (плаћа послодавац);
(3) накнада за коришћење комуналних добара од општег интереса по стопи коју утврди својом одлуком надлежна јединица локалне самоуправе (највише до 2% а плаћа је послодавац).
Основицу за утврђивање обавезе из става 1 овог члана чини износ бруто личног примања утврђен примјеном прерачунатих стопа на нето лична примања.
Прерачуната стопа добија се по следећој формули:
100 х % порез на лична примања
пр. стопа = ---------------
100 - % порез на лична примања
Примјеном прописаних стопа из закона, прерачуната стопа износи:
100 х 32
пр. стопа = ---- = 47,05 (коефицјент за прерачун нето у бруто 1,47)
100 - 32
ПРИМЈЕР:
За нето примање од 100 н. динара бруто основица за обрачун обавеза према јавним приходима износи 147 н. динара (100 х 47 = 147).
