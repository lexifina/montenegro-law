# Члан 6
## 4. Лична примања по основу накнаде за вријеме породиљског одсуства
На лична примања по основу накнаде за вријеме породиљског одсуства обрачунавају се обавезе по основу јавних прихода, и то:
(1) порез на лична примања по стопи од 32%;
(2) допринос за социјално осигурање, по стопама прописаним законом, и то: за пензијско и инвалидско осигурање 24%, за здравствено осигурање 15% и за осигурање од незапослености 0,5% (плаћа исплатилац);
(3) накнада за коришћење комуналних добара од општег интереса по стопама коју утврди својом одлуком надлежна јединица локалне самоуправе (највише до 2% а плаћа је исплатилац).
Основицу за обрачун обавеза из става 1 овог члана чини износ бруто примања утврђен на начин из члана 5 овог упутства.
