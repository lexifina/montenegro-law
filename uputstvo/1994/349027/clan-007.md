# Члан 7
## 5. Лично примање до једне трећине преко пуног радног времена
На примања до једне трећине преко пуног радног времена обрачунавају се обавезе по основу јавних прихода по стопама које се примјењују на примања запослених који раде са пуним радним временом, осим доприноса за пензијско и инвалидско осигурање који се плаћа по стопи од 8%.
Из бруто зараде запослених надокнађују се:
(1) порез на лична примања по стопи од 32%.
(2) допринос за здравствено осигурање по стопи од 7%;
(3) допринос за осигурање од незапослености по стопи од 0,5%.
Из средстава послодавца плаћају се:
- допринос за пензијско и инвалидско осигурање за случај инвалидности и тјелесног оштећења проузрокованих повредом на раду или професионалном болешћу по стопи од 8%,
- допринос за здравствено осигурање по стопи од 7,5%,
- допринос за осигурање од незапослености по стопи од 0,5%,
- накнада за коришћење комуналних добара од општег интереса по стопи коју утврди својом одлуком надлежна јединица локалне самоуправе (највише до 2%).
Основицу за обрачун обавеза из овог члана чини бруто примање утврђено на начин из члана 2 овог упутстава (исти начин као за лична примања по основу зарада запослених).
