# Član 14
Ponuda za kupovinu državnih zapisa naročito sadrži:
1) datum donošenja odluke o emisiji državnih zapisa koji se namjeravaju
kupiti;
2) ISIN broj državnih zapisa koji se namjeravaju kupiti;
3) registarski broj ponuđača kod Centralne Depozitarne agencije; 4) nominalnu vrijednost državnih zapisa koji se namjeravaju kupiti;
5) broj državnih zapisa koji se namjeravaju kupiti;
6) datum dospijeća državnih zapisa koji se namjeravaju kupiti;
7) diskontnu stopu po kojoj se namjeravaju kupiti državni zapisi, ako se
daje konkurentna ponuda;
8) broj računa ponuđača sa kojeg će se izvršiti uplata sredstava;
9) izjavu o načinu plaćanja.
