# Члан 7
Цијена основних врста хљеба произведеног од пшеничног брашна образују се на бази цијена пшенице из члана 3. ове уредбе у односу који не може бити већи од 1:4,5 за хљеб од брашна тип "850" односно 1:5,5 за хљеб од брашна тип "500".
Цијене основних врста хљеба из става 1. овог члана сматрају се малопродајним цијенама.
