# Члан 2
Порески обвезници су дужни да кроз посебну евиденцију обезбиједе дневно исказивање наплаћене, односно фактурисане реализације у обрачунским јединицама.
Обавеза из става 1 овог члана односи се и на примљени аванс по основу промета производа и услуга.
Обрачунска јединица представља динарску противвриједност једне ДЕМ утврђене по средњем курсу Народне банке Југославије.
Број обрачунских јединица из става 1 овог члана се утврђује из односа реализације и вриједности обрачунске јединице из става 3 овог члана на дан наплате, односно фактурисања.
Динарски износ пореске обавезе утврђује се као производ пореске обавезе исказане у обрачунским јединицама и вриједности обрачунске јединице из става 3 овог члана у моменту плаћања пореза.
