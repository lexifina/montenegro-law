# Član 48
Organi državne uprave donose godišnji program rada.
Program rada sadrži, naročito: pregled aktivnosti kojima se ostvaruju funkcije organa (pojedinačno po funkcijama); osnovnu sadržinu posla; nosioce posla (organizaciona jedinica, tim, službenik i dr.); rokove (mjesečno i kvartalno i dr.); subjekte saradnje (pojedinačno naznačenje su-bjekata i oblika kojima će se saradnja ostvariti) i pregled sredstava potrebnih za programski period.
Program rada donosi ministar, odnosno starješina organa uprave. Program rada organa uprave donosi se uz saglasnost ministarstva koje nad tim organom vrši nadzor.
