# Član 8
Promjena oznake stepena tajnosti dokumenta označava se precrtavanjem dosadašnje oznake stepena tajnosti, upisivanjem nove oznake stepena tajnosti koja je određena tom dokumentu.
Ukidanje stepena tajnosti podatka označava se precrtavanjem stepena tajnosti podatka upisivanjem oznake "PRESTANAK TAJNOSTI" i označavanjem datuma ukidanja.
Akt kojim je promijenjen ili ukinut stepen tajnosti podatka prilog je dokumenta čiji je stepen tajnosti promijenjen ili ukinut.
