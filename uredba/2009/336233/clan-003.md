# Član 3
(1)Priprema Plana vrši se na osnovu radnog programa nadležnog organa uprave (u daljem tekstu: Radni program).
(2)Radni program sadrži:
1) razloge za pripremu Plana ;
2) područje za koje se vrši priprema Plana ;
3) rokove za pripremu pojedinih djelova Plana ;
4) nazive nadležnih organa i organizacija koje će učestvovati u postupku pripreme Plana ;
5) rok za obrazovanje radnog tima za pripremu Plana ;
6) period određen za javnu raspravu u postupku pripreme Plana ;
7) pregled zadataka u postupku pripreme Plana ;
8) pregled izvora i načina dobijanja podataka u postupku pripreme Plana.
(3)Radni program se objavljuje na Internet stranici nadležnog organa uprave.
