# Члан 2
Исплата обештећења из члана 1 ове уредбе обрачунава се према вриједности која одговара 3% од преосталог неисплаћеног износа обештећења утврђених коначним рјешењем Комисије.
Обрачун годишње рате из става 1 овог члана за сваког бившег власника односно насљедника извршиће се према његовом удјелу (насљедни удио) у преосталом неисплаћеном износу обештећења утврђеним рјешењем Комисије.
