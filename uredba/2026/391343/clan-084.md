# Član 84
## Imenovanje zastupnika za planiranje isključenja
(1) OPS je agent za planiranje isključenja za svaki relevantni element mreže u svom vlasništvu.
(2) Za relevantne elemente koji nijesu u vlasništvu OPS-a, vlasnik imenuje agenta za planiranje isključenja ili djeluje kao agent za planiranje isključenja za predmetni relevantni element i obavještava svog OPS-a o tom imenovanju.
