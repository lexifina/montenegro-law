# Član 17
## Pilot program
Prije donošenja programa obrazovanja, a zbog uvođenja organizacionih promjena kod poslodavca, primjene savremenih tehnologija i sl, mogu se realizovati pilot programi sa jasno definisanim ishodima učenja.
Pilot program realizuje pravno lice.
Po završetku pilot programa, organizator pilot programa izdaje uvjerenje o pohađanju pilot programa.
Realizaciju pilot programa prati Centar.
Pravno lice iz stava 2 ovog člana određuje organ državne uprave nadležan za poslove prosvjete (u daljem tekstu: Ministarstvo), na predlog Centra.
