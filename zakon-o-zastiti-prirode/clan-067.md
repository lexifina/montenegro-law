# Član 67
## Godišnji program upravljanja
Godišnji program upravljanja izrađuje i donosi upravljač, uz saglasnost Ministarstva, odnosno nadležnog organa lokalne uprave i uz prethodno pribavljeno mišljenje Agencije.
Godišnji program upravljanja dostavlja se Ministarstvu, odnosno nadležnom organu lokalne uprave do 15. novembra tekuće godine za narednu godinu.
Godišnji program upravljanja mora da bude usklađen sa planom upravljanja.
Sadržaj godišnjeg programa upravljanja iz stava 1 ovog člana propisuje Ministarstvo.
