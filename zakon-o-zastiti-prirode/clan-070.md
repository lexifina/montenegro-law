# Član 70
## Privremeni godišnji program upravljanja
Za nova zaštićena područja, upravljač je dužan da donese privremeni godišnji program upravljanja u roku od šest mjeseci od dana proglašavanja tog zaštićenog područja, uz prethodnu saglasnost Ministarstva, odnosno organa lokalne uprave i uz prethodno mišljenje Agencije.
Privremeni godišnji program upravljanja izrađuje se u skladu sa sadržajem godišnjeg programa upravljanja iz člana 67 ovog zakona.
Privremeni godišnji program upravljanja iz stava 1 ovog člana primjenjuje se do donošenja plana upravljanja, a najviše se može donijeti jedan privremeni godišnji program upravljanja.
