# Član 23
## Donošenje obrazovnog programa privatne ustanove
Sadržaj i postupak donošenja obrazovnog programa u privatnoj ustanovi određuje se aktom o osnivanju ustanove.
Obrazovni program iz stava 1 ovog člana postaje javno važeći program kada nadležni savjet utvrdi da odgovara javno važećem programu za pojedinu oblast obrazovanja i vaspitanja.
