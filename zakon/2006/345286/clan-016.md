# Члан 16
Предсједник гласачког одбора на гласачком мјесту са највећим бројем уписаних бирача на претходним изборима у Црној Гори бира се из реда референдумске опције чији кандидат није изабран за предсједника општинске комисије.
Предсједници осталих гласачких одбора именују се од стране представника обје референдумске опције, наизмјенично, по редосљеду гласачких мјеста према броју уписаних бирача на бирачким мјестима на претходним изборима у Црној Гори.
