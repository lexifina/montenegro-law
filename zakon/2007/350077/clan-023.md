# Član 23
## Horizontalni referentni sistem
Horizontalni referentni sistem predstavlja dvodimenzionalni koordinatni podskup prosto- rnog referentnog sistema u kome se položaj tačaka i objekata izražavaju dvodimenzionalnim, pra-vouglim, krivolinijskim koordinatama, odnosno geodetskom dužinom i širinom u odnosu na referentni dvoosni obrtni elipsoid geodetskog referentnog sistema GRS 80 (Geodetic Reference System 80).
