# Član 3
U članu 3 stav 2 riječi: "opšta gimnazija" zamjenjuju se riječima: "opšta i specijalistička gimnazija".
Stav 3 mijenja se i glasi:
"U opštoj gimnaziji mogu se u posebnim odjeljenjima realizovati posebni obrazovni programi specijalističke gimnazije (matematička, filološka, i sl.), uz odobrenje organa državne uprave nadležnog za poslove prosvjete (u daljem tekstu: Ministarstvo)."
Poslije stava 3 dodaje se novi stav koji glasi:
"U sportskoj gimnaziji realizuje se program opšte gimnazije sa prilagođenim izvođenjem."
