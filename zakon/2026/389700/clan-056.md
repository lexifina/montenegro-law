# Član 56
## Saradnja između operatora distributivnog sistema i operatora prenosnog sistema
(1) Operator distributivnog sistema i operator prenosnog sistema međusobno sarađuju u planiranju i upravljanju svojim mrežama.
(2) Operator distributivnog sistema i operator prenosnog sistema razmjenjuju sve potrebne informacije i podatke o radu proizvodnih jedinica i upravljanju potrošnjom, svakodnevnom radu svog sistema i dugoročnom planiranju investicija u mrežu, kako bi se obezbijedio isplativ, siguran i pouzdan razvoj i rad njihovih sistema.
(3) Operator distributivnog sistema i operator prenosnog sistema međusobno sarađuju radi postizanja koordinisanog pristupa resursima, kao što su distribuirana proizvodnja, skladištenje energije ili upravljanje potrošnjom.
