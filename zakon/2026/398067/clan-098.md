# Član 98
Godišnji program rada lokalne uprave donosi se do kraja tekuće godine za narednu godinu.
Polazne osnove za pripremu godišnjeg programa rada lokalne uprave su srednjoročni program rada lokalne uprave i mjere ekonomske politike za tekuću godinu.
Godišnjim programom rada lokalne uprave utvrđuju se osnovni zadaci, nosioci tih zadataka, rokovi za njihovo izvršenje i pokazatelji uspjeha.
Godišnji program rada lokalne uprave sastoji se od tematskog i normativnog dijela.
